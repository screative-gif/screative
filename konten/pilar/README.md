## Isi folder pilar
- `README.md`: ringkasan pilar (apa, untuk siapa, jadwal, alur, file lain)
- `formula.md`: struktur konten (cover, alur slide, CTA, caption)
- `aturan.md`: aturan tetap dari keputusan user (yang harus selalu sama)

Pilar baru: salin struktur ini, lalu tambahkan barisnya di tabel di atas dan di `konten/brand/brand.md`.
